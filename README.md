# Flores amarillas para ti

Una sorpresa romántica para compartir: un ramo de flores amarillas animado y una carta que se abre al recibir el regalo.

## Personalizar la carta

Edita el objeto GIFT al inicio de src/App.tsx. Ahí puedes cambiar el nombre de quien recibe las flores, la firma, el saludo, los párrafos y el cierre.

## Ejecutar

Instala las dependencias con pnpm install. Inicia la página con PORT=5173 BASE_PATH=/ pnpm dev. Para compilar, ejecuta PORT=5173 BASE_PATH=/ pnpm build.

La página respeta la preferencia de movimiento reducido del dispositivo y se adapta a pantallas pequeñas.
